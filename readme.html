Overview
This screen explains the workflow for each role in the app.
The same calendar can be shared by multiple guides, but each role uses it differently.
Admin
Tour Configuration: create and maintain the tour templates that guides can book.
Pre-paid tours: define ticket price, commission, invoice organization and invoice email.
Free tours: define the fee per participant that the guide owes to the platform after the tour.
Shareable / Private: shareable tour types are visible to guides sharing the calendar. Private ones remain hidden in details but still block conflicting bookings.
Invoice flow: when participants are locked on a pre-paid tour, the invoice PDF is generated and stored automatically.
Coordinator
Share My Calendar: invite another guide to work on the same calendar. Invitations must be accepted before the calendar is shared.
Availability: each guide marks their available days. Only available guides appear when creating a new tour.
Booking a tour: select a day, start time, guide and tour type. If the assigned guide is not yourself, the booking is created as pending.
Confirmation: the assigned guide must accept the pending tour. Accepted tours appear in green; pending tours appear in orange.
Conflicts: the app blocks overlapping tours for the same guide, including private tours not visible in detail.
Notifications: guides receive push notifications for share invites, accepted shares, pending tours and some tour updates.
Guest
Participants: after a tour is accepted, guides can add or import participant names and group sizes.
Attendance: each participant should be marked as arrived or no-show before locking the final list.
Lock participants: once locked, the attendance list becomes final and cannot be edited again.
Pre-paid tours: only arrived participants are counted on the invoice.
Free tours: after lock, the guide enters the amount received and the app shows what is due to the platform from the per-participant fee.
Invoice email: for pre-paid tours, the guide can open the PDF and prepare an email to the invoicing organization.
