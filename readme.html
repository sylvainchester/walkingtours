Overview
Walking Tours is a shared planning tool for guides. It combines calendar planning, participant tracking, invoice preparation, push notifications and email booking review.
The main sections are: Walking Tours, Summary List, Booking Imports, Share My Calendar, My Availability, My Profile, Tour Configuration and Manage Invoices.
Tour Configuration
Tour types: all tours are based on a configured tour type.
Pre-paid: define ticket price and platforms. Each platform can have commission, invoice requirement and invoice email.
Free tour: platforms are still used, but the value becomes the fee per participant owed to the platform.
Platforms: only platforms defined in the tour type are valid for imports and participant assignment.
Shareable / Private: shareable types can be used by shared guides. Private types still block conflicts but hide details from other guides.
Schedule templates: recurring day/time templates can automatically create future tours until an end date.
Share Calendar
Share My Calendar: one guide can invite another by email.
Invitation flow: the second guide receives the invitation in the Share screen and must accept it before the calendar becomes shared.
Shared work: once accepted, guides can see the same planning space and coordinate tours.
Validation toggle: a shared calendar can require acceptance for tours created by the other guide, or accept them immediately with notification only.
Notifications: share requests, accepted shares, removals and tour events trigger push notifications.
Availability And Booking
Walking Tours: the main page shows one month at a time with availability, tour count and participant count by day.
Availability: guides are available by default and can mark days unavailable in My Availability.
Create Tour: pick a day, time, guide and tour type. End time defaults automatically.
Multiple Guides: in a tour modal, choose Multiple Guides to assign the tour to every guide sharing the calendar.
Pending tours: if validation is required, a tour created for another guide stays pending until accepted.
Conflict protection: the app blocks overlapping tours for the same guide.
Summary List: shows all future tours in chronological order and allows bulk guide reassignment.
Participants And Lock
Participants: after a tour is accepted, guides can add participants manually or import them from a screenshot.
Attendance status: each participant must be marked as arrived or no-show.
Lock participants: locking is final. After lock, participants can no longer be changed.
Validation before lock: all participants must have a status, and at least one participant must be marked as arrived.
Pre-paid tours: lock freezes the list. Invoices are created later from Manage Invoices.
Free tours: after lock, the guide can enter the amount received and the app shows the platform amount due.
Booking Imports
Manual check: the guide forwards booking emails, then uses Check new emails in Booking Imports.
Email recognition: the app links imports to the guide email, plus optional booking import alias emails from My Profile.
Matching: imports are matched only against tours belonging to that guide or to guides sharing the same calendar.
Review flow: each import is reviewed before insertion. Rejected imports disappear. Confirmed imports stay visible in a green history list.
Original email: the raw email can be expanded to compare the proposed import with the source.
Profile And Invoices
My Profile: stores guide identity, bank details and booking import alias emails.
Manage Invoices: creates one invoice by platform and date range using locked tours only.
Invoice scope: one invoice can include tours from all guides sharing the same calendar.
History: invoices are listed with open and delete actions.
